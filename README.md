# 🚀 Cleo-IA - Base de Conhecimento para scripts CLEO 5.4 (GTA SA v1.0 US)

Salve! Esse repositório é a minha base de dados pessoal que eu montei para **treinar inteligências artificiais** (como o Qwen Coder) a programarem scripts CLEO e SCM para o GTA San Andreas sem cometer erros bobos. 

Aqui dentro juntei toda a documentação essencial do Sanny Builder, limites internos da engine do jogo e correções de erros estruturadas direitinho em pastas.

---

## 📂 Como o projeto está organizado:

*   **`Credits` / `Introduction`:** Quem fez as ferramentas e o básico para começar.
*   **`Language`:** Toda a estrutura de dados, variáveis e sintaxe certa do Sanny Builder.
*   **`Scm Documentation/Gta San Andreas`:** O "manual do carro". Aqui tem os limites de memória da engine (variáveis locais, blips no radar, etc.) para a IA não criar scripts que crasham o jogo.
*   **`TroubleShooting/Error Messages`:** Guia completo de erros (do 0001 ao fim) para ajudar a IA a debugar e consertar códigos quebrados.
*   **`Version History`:** Evolução das ferramentas para garantir compatibilidade com as novidades da CLEO 5+.

---

## 🛠️ Qual é o objetivo disso aqui?
Dar um "super cérebro" para ferramentas de IA. Quando conecto esse repositório no Qwen Coder, a IA lê todas essas pastas e passa a gerar códigos válidos de primeira, respeitando a sintaxe moderna e as regras do GTA SA v1.0 US.

## 🤝 Créditos
Toda a documentação técnica foi extraída e organizada a partir dos manuais oficiais do **Sanny Builder** e da **CLEO Library**.
