# 🚀 Cleo-IA - O Guia Da IA Para criar scripts CLEO 5.4 para GTA SA v1.0 US/SAMP

Este repositório é uma base de conhecimento ultra-estruturada para **alimentar e treinar modelos de IA** (como o Qwen Coder) na criação de scripts CLEO 5+, focado em estabilidade (zero crashes) utilizando engenharia reversa e injeção de memória (Memory Hacking).

---

## 📂 Estrutura e Conteúdo Atualizado

O repositório está organizado para cobrir do básico ao avançado:

1.  **📖 Introdução:** Contexto sobre Sanny Builder e ferramentas da comunidade.
2.  **📝 Linguagem:** Sintaxe, tipos de dados (byte, dword, float) e manipulação de strings.
3.  **⚙️ Modos de Edição:** Padrões do Sanny Builder 4 (SB4).
4.  **📊 Documentação SCM:** Limites da engine (variáveis, blips, threads).
5.  **🔬 OffSets & Memória (NOVO):** Mapeamento completo dos endereços de memória da v1.0 US (`GTA_SA.EXE`), incluindo:
    *   **Básico:** Dinheiro, Procurado, ID de Rádio, Gravidade.
    *   **Estatísticas:** Tags, Ferraduras, Ostras, Progressos de Namoradas.
    *   **Timers & Rendering:** Clima, Tempo, DirecX/D3D9 (Hooks).
6.  **🛠️ TroubleShooting:** Guia de erros do compilador.
7.  **🔄 Version History:** Evolução da CLEO Library.
8.  **🎯 Examples:** Scripts funcionais como Godmode (`0A8C: write_memory`).

---

## 🧠 Como usar
Vincule este repositório como RAG/Contexto na sua IA. Solicite scripts cruzando informações da pasta `OffSets` e `Language` para garantir o uso correto de `0A8C: write_memory` para injeção direta de dados na memória.
