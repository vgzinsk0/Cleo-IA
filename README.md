# 🚀 Cleo-IA - Base de Conhecimento para scripts CLEO 5.4 (GTA SA v1.0 US)

Salve! Este repositório é uma base de dados para treinar IAs (como o Qwen Coder) a programar scripts CLEO/SCM para GTA San Andreas, focando na sintaxe correta e evitando erros de `crash`.

## 📂 Organização
*   **`Examples Cleo`**: Scripts modelo, incluindo agora o `Godmode ON-OFF.txt` (focado em toggle, imunidade e `0A8C` Memory Hacking).
*   **`Scm Documentation`**: Limites da engine (variáveis, blips) para evitar crashes.
*   **`TroubleShooting/Error Messages`**: Guia para correção de erros.

## 💡 Objetivo
Conectar este repositório a IAs para que gerem códigos válidos, seguindo regras da CLEO 5+ e GTA SA v1.0 US.

## 🤝 Créditos
Documentação baseada nos manuais do **Sanny Builder** e **CLEO Library**.
