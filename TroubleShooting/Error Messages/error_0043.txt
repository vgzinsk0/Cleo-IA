Error Code: 0043
Title: Invalid array index
Source: https://docs.sannybuilder.com/troubleshooting/errors/0043
========================================================================

The array element index is not a variable.
Possible solutions: use a global or local variable:
`
$var(0,2i) = 1 // error
$index = 0
$var($index,2i) = 0 // OK
or
var
$var: Array 2 of Integer
end
$var[0] = 0 // OK
`
