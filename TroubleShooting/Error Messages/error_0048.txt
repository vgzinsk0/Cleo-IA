Error Code: 0048
Title: Error reading array size
Source: https://docs.sannybuilder.com/troubleshooting/errors/0048
========================================================================

The size of an array is missing or is not a number (e.g. a string literal).
Possible solutions: use a valid positive number greater than 0:
`
0@(1@,i) = 0 // error
0@(1@,"1"i) = 0 // error
0@(1@,1i) = 0 // OK
`
