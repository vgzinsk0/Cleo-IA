Error Code: 0047
Title: Invalid array size
Source: https://docs.sannybuilder.com/troubleshooting/errors/0047
========================================================================

The size of an array can't be a value of zero or a negative number.
Possible solutions: use a valid positive number greater than 0:
`
0@(1@,0i) = 0 // error
0@(1@,-1i) = 0 // error
0@(1@,1i) = 0 // OK
`
