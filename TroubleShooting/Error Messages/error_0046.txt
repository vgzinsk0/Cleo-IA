Error Code: 0046
Title: Invalid array syntax
Source: https://docs.sannybuilder.com/troubleshooting/errors/0046
========================================================================

String variable notation (@s, s$) can't be used anywhere in the array syntax.
Possible solutions: use a global or local variable ($, @):
`
0@s($index,1i) = 2 // error
0@(s$index,1i) = 2 // error
0@($index,1i) = 2 // OK
`
