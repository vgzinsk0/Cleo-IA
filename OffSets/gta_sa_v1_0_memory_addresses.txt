--- SCM - THREADS ---

NOTA SOBRE TAMANHO DE BLOCO: 0xA8B430 = Inicio do pool de threads. Ha duas
filas: as threads ativas e as inativas. Cada thread tem tamanho de 224 (0xE0)
bytes.

0xA8B42C - [ptr] - Ponteiro para a primeira thread SCM ativa
0xA8B428 - [ptr] - Ponteiro para a primeira thread SCM inativa

Thread+0x00 - [void*] - Ponteiro para a proxima thread na fila (next thread in queue)
Thread+0x04 - [void*] - Ponteiro para a thread anterior na fila (previous thread in queue)
Thread+0x08 - [char] - Nome da thread dado pelo opcode 03A4 (char 8)
Thread+0x10 - [dword] - IP base da thread (usado nas missoes e scripts externos para calcular um endereco global de um offset de jump local)
Thread+0x14 - [dword] - IP atual (Current IP)
Thread+0x18 - [dword] - Pilha de retorno (stores the current IP when a gosub executed, dword 8)
Thread+0x38 - [word] - Ultimo indice do item da pilha de retorno (Last item index of the return stack)
Thread+0x3C - [dword] - Array de variaveis locais (Local variables array, dword 32)
Thread+0xBC - [dword] - Timers de incremento automatico (Automatically incrementing timers, dword 2)
Thread+0xC4 - [boolean] - Flag de thread ativa (Thread active flag)
Thread+0xC5 - [boolean] - Resultado do IF (IF result)
Thread+0xC6 - [boolean] - Flag de missao (Mission flag)
Thread+0xC7 - [boolean] - Flag de script externo (External script flag)
Thread+0xC8 - [boolean] - Flag desconhecida (no menu?). Usada em 03E5
Thread+0xC9 - [boolean] - Flag desconhecida (ID de um script atribuido?)
Thread+0xCC - [dword] - Tempo de wakeup (setado por 0001)

--- SCM - RESTART LOCATIONS ---

NOTA: Veja tambem: opcodes 016C e 016D / bloco 8 do arquivo de save.
Um jogo nao-modificado tem 7 localizacoes de restart para "busted" e 8 para
"wasted". A estrutura de memoria sugere um limite de 10 para ambos.

0xA43268 - [dword] - Numero de estruturas de busted (number of busted structures)
0xA4326C - [dword] - Numero de estruturas de wasted (number of wasted structures)
0xA43270 - [float[10]] - Numeros de cidade para estruturas de busted (1 = LS / 2 = Country+SF / 3 = Desert+LV)
0xA43298 - [float[10]] - Angulos para estruturas de busted
0xA432C0 - [float[10]] - Numeros de cidade para estruturas de wasted (1 = LS / 2 = Country+SF / 3 = Desert+LV)
0xA432E8 - [float[10]] - Angulos para estruturas de wasted
0xA43310 - [float] - float nao usado, apenas definido ate (0.005 * 0.0625 = 0.0003125); 1/0.0003125 = 3200.0
0xA43318 - [float[3][10]] - x,y,z - coordenadas de respawn para estruturas de wasted
0xA43390 - [float[3][10]] - x,y,z - coordenadas de respawn para estruturas de busted
0xA43408 - [byte[12]] - desconhecido; correspondendo aos 12 bytes desconhecidos do bloco 8 do save; 0x01 apos estruturas de busted
0xA43414 - [byte[12]] - desconhecido; correspondendo aos 12 bytes desconhecidos do bloco 8 do save; 0x0F apos estruturas de busted
0xA43420 - [end] - Fim da estrutura

NOTAS:
- Os numeros de cidade e angulos tem as estruturas de busted primeiro, mas as
  coordenadas tem as estruturas de wasted primeiro.
- Nao ha certeza sobre o final desta estrutura; nada reconhecivel do bloco 8
  do save foi identificado apos 0xA43420.

--- SCM - MISC ---

NOTA SOBRE TAMANHO DE BLOCO: 0xA4892C = Inicio do pool que armazena os handles
de veiculos que capotaram. Ha 6 elementos, cada um com:

FlippedVeh+0x00 - [dword] - Handle do veiculo para verificar se capotou. Armazenado pelo opcode 0190.
FlippedVeh+0x04 - [dword] - Tempo em ms passado desde o momento em que o veiculo capotou. Usado pelo opcode 018F

NOTA SOBRE TAMANHO DE BLOCO: 0xA90850 = Inicio da lista de limpeza de missao
(mission cleanup list). Esta lista mantem os handles de quaisquer entidades
criadas durante uma missao. Quando o opcode 00D8 e executado (normalmente no
final de qualquer missao), o jogo le esta lista e destroi tudo que esta
armazenado la. Numero maximo de itens na lista e 75. Cada item tem a seguinte
estrutura:

MissionCleanup+0x00 - [byte] - Tipo de entidade (Entity type):
    Valores: 1 = veiculo / 2 = actor / 3 = object / 4 = particle /
    5 = group (opcode 062F) / 7 = AS_origin (opcode 061D) /
    8 = action_sequence / 9 = decision maker / 11 = searchlight /
    13 = txd_dictionary
MissionCleanup+0x04 - [dword] - handle da entidade (um indice no pool apropriado)
