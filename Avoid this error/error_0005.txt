===========================================================================
ERROR_0005: INVALID OBJECT-ORIENTED SYNTAX IN STANDARD CS SCRIPTS (ERROR 0013)
===========================================================================

1. OBJECT-ORIENTED COMMAND LIMITATION:
- NEVER use object-oriented commands like 'Model.Load()', 'Model.Available()', 'Actor.GiveWeaponAndAmmo()', or 'Text.PrintHighPriority()' inside standard compiled scripts using the '{$CLEO .cs}' directive.
- Sanny Builder 4 will block these expressions with Error 0013: "Unknown directive [Command]". This syntax is exclusive to modular files ('{$CLEO .mod}') that import external module components.

2. CORRECT SCRIPTING SINTAX FOR STANDARD CLEO CS:
- For standard scripts, ALWAYS utilize the clean, native, and stable command architecture recognized by the core compiler definitions for Grand Theft Auto San Andreas.
- CORRECT REQUISITION PATTERN:
  request_model 2@
  while not has_model_loaded 2@
      wait 0
  end
- CORRECT WEAPON DELIVERY PATTERN:
  01B2: give_actor $PLAYER_ACTOR weapon 31 ammo 500 // ID 31 = M4

3. MODEL CLEANUP PATTERN:
- Use the direct native command to flush the memory safely:
  mark_model_as_no_longer_needed 2@
