===========================================================================
ERROR_0013: UNRESOLVED CLEO OPCODES (MISSING {$USE CLEO} DIRECTIVE)
===========================================================================

1. COMPILER FAILURE:
- Using CLEO-specific keywords or commands such as 'is_key_pressed' (Opcode 0AB0) without declaring the CLEO extension set causes the compiler error: "Opcode 0AB0 is not found in the standard opcodes and current script extensions."
- In Sanny Builder 4, SBL v1.1 requires explicit extension loading to resolve non-native engine opcodes.

2. INCORRECT HEADER:
  {$CLEO .cs}
  {$VERSION CLEO_5.4}
  script_name 'INFAMMO'

3. CORRECT HEADER:
  {$CLEO .cs}
  {$USE CLEO}
  {$VERSION CLEO_5.4}
  script_name 'INFAMMO'

4. REINFORCEMENT FOR AI GENERATION:
- ALWAYS place '{$USE CLEO}' at line 0002 immediately below '{$CLEO .cs}'. Never write CLEO scripts without loading the extension module.
