===========================================================================
ERROR_0009: MISSING SCRIPT NAME DIRECTIVE IN SBL v1.1
===========================================================================

1. UNNAMED SCRIPT COMPILATION WARNING / FAILURE:
- Compiling a standalone CLEO (.cs) script without an explicit 'script_name' directive causes memory allocation ambiguity and thread tracking issues inside GTA San Andreas runtime.
- SBL v1.1 requires script naming for proper debugging and report generation.

2. CORRECT SCRIPT NAME REGISTRATION:
- Always declare 'script_name' immediately after script headers and directives.
- Example:
  {$CLEO .cs}
  {$USE CLEO}
  script_name 'INFAMMO'

3. REINFORCEMENT:
- The script name string must be 1 to 7 uppercase alphanumeric characters wrapped in single quotes.
