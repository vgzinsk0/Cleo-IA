===========================================================================
ERROR_0012: UNKNOWN DIRECTIVE ELSE (SBL v1.1 MANDATORY 'THEN' DIRECTIVE)
===========================================================================

1. DIRECTIVE PARSING FAILURE:
- In Sanny Builder 4 using SBL v1.1 mode, writing an 'if' condition directly followed by an 'else' block or nested statements without an explicit 'then' keyword causes the compiler to throw "Diretiva desconhecida else" (Unknown directive else).
- SBL v1.1 strictly enforces block-structured syntax where every conditional branch MUST be explicitly opened with 'then'.

2. INCORRECT PATTERN:
  if is_key_pressed 45
      if 6@ == 0
          // Code block
      else
          // Code block
      end
  else
      6@ = 0
  end

3. CORRECT PATTERN:
  if is_key_pressed 45
  then
      if 6@ == 0
      then
          // Code block
      else
          // Code block
      end
  else
      6@ = 0
  end

4. REINFORCEMENT FOR AI GENERATION:
- ALWAYS append 'then' on a new line immediately after every 'if' condition before writing the condition body or 'else' branch.
